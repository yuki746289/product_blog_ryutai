# product_blog_ryutai site-specific development rules

更新日: 2026-09-16

## 1. 数式画像のLaTeX/MathJax化

### 最優先: 元画像完全一致

- 数式画像をLaTeX/MathJaxへ変換する場合、元画像の式を忠実に再現する。
- 数学的に同値であっても、一般化・省略・因数分解・展開・項順変更・記号変更・移項・行列化・総和記号化など、元画像と異なる式への書き換えは禁止する。
- 文字、記号、大文字/小文字、添字、上付き、係数、符号、括弧、等号、積分領域、微小量、行列成分、ベクトル成分、項順をすべて元画像と照合する。
- 複数の元画像を1個の一般化式へ統合しない。
- 長い式を短くするために数式自体を変更しない。表示上はMathJaxの自動改行を使用する。
- 各変換式に式IDと元画像パスを保持し、元画像を削除しない。

### 誤記・補足の扱い

- 元画像に誤記と思われる箇所があっても、原文式は元画像どおり掲載する。
- 誤記候補、理論上の修正、補足、より正確な説明は、原文式とは別に表示する。
- 修正版を掲載する場合は「原文」と「修正版（参考）」を明確に区別し、原文式を残す。
- 利用者が明示的に原文式そのものの変更を承認した場合のみ置換可能とする。

### 完了条件

- `.document/CHECKLIST_FORMULA_CONVERSION.md` を必ず使用する。
- 全式について元画像とのPass 1（転記照合）とPass 2（MathJax表示照合）を実施する。
- 1式でも未照合の場合、そのページを数式変換完了として扱わない。
- 2026-09-16以前に変換済みの式も、新チェックリストで再監査する。

## 2. デザイン方針 v1.5

2026-09-16時点の採用方向は次のとおり。

- 本文デザイン: `D Monochrome Notes` をベースとする。
- PCナビゲーション: 左固定メニューを廃止し、`多層メニュー実動サンプル` のトップカテゴリ＋メガメニュー方式をベースとする。
- スマートフォン: ハンバーガー＋ドロワー＋多層アコーディオン方式をベースとする。
- PCのトップカテゴリは原則として `物理 / 流体力学 / 有限要素法 / メッシュ / SIMPLE法 / 伝熱工学 / Fortran / その他` の8カテゴリとする。
- 深い階層を横方向の多段フライアウトで展開しない。メガパネル内のグループ・インデントで表現する。
- デザイン変更で既存URL、数式、本文内容を意図せず変更しない。

## 3. 本番反映

- `develop` で確認後、利用者の明示承認前に本番FTPへ反映しない。
- デザイン変更と数式内容変更を同一作業として混在させず、差分を追跡できるようにする。

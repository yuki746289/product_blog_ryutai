# v1.5 画面・画面遷移

更新日: 2026-09-16

## UI-NOTICE-001 トップページ [KEEP]
`index.html` の「お知らせ等」に更新内容と `revision_history.html` へのリンクを表示する既存仕様を維持する。

## UI-HISTORY-001 修正履歴導線 [KEEP]
修正履歴へ到達できる導線を維持する。新ナビゲーション適用後は、左メニュー依存ではなく上部補助メニュー等から到達可能にする。

## UI-NAV-004 現行左メニュー [TRANSITION]
本体デザイン切替までの暫定仕様として、現行左メニューの文字切れ・不要スクロールを発生させない。

## UI-NAV-005 採用ナビゲーション [TARGET]

### PC / タブレット
- 左固定メニューを廃止する。
- ヘッダー直下に8カテゴリを横並びで表示する。
  1. 物理
  2. 流体力学
  3. 有限要素法
  4. メッシュ
  5. SIMPLE法
  6. 伝熱工学
  7. Fortran
  8. その他
- カテゴリをクリックすると、ヘッダー下に1枚のメガメニューを展開する。
- メガメニュー内で2階層目を章グループとして分け、3～4階層目は列内インデントで表現する。
- 多段フライアウトで横方向へ連続展開しない。
- 同一位置でカテゴリを切り替えられる。
- 外側クリック、Escapeで閉じる。

### スマートフォン
- ハンバーガーボタンから右側ドロワーを開く。
- カテゴリは縦並びアコーディオンとする。
- 下位階層も入れ子のアコーディオンで表示する。
- ドロワー内部を縦スクロール可能とする。
- 閉じたドロワーには `inert` 相当の制御を行い、画面外リンクへキーボードフォーカスが移動しないようにする。

### 参考実装
`design_samples/v1.5/gray/mega-menu-preview.html`

## UI-DESIGN-002 採用本文デザイン [TARGET]
本文デザインは **D / Monochrome Notes** をベースとする。

- 白背景を基本とする。
- 色数を抑え、黒～グレーの文字・罫線を中心にする。
- 見出し、余白、罫線で章構造を示す。
- 本文・数式を主役にし、装飾カードを多用しない。
- 左サイドバーを置かない。
- 数式ブロックは周囲の本文と明確に区別しつつ、強い背景色は使わない。
- PC/スマホとも本文中心の構成を維持する。

参考実装: `design_samples/v1.5/gray/monochrome-notes.html`

## UI-FORMULA-001 数式表示 [TARGET]

- MathJaxで表示する数式内容は元画像に忠実にする。
- 長い式は式自体を短縮・一般化せず、MathJaxの自動改行を使う。
- 誤記候補・補足・修正版は、原文式とは別の補足ブロックとして表示する。
- 必要に応じて「原文」「補足」「修正版（参考）」を視覚的に区別するが、原文式の内容は変更しない。

## UI-HISTORY-002 修正履歴画面 [MOD]
修正履歴テーブルは次の列を表示する。
1. No.
2. 修正種類
3. 対象
4. 修正内容

`R-*`形式の管理IDは利用者向け列として表示しない。

## 画面遷移（本体適用後の基本像）

`ホーム / 補助メニュー`
→ `上部8カテゴリ`
→ `メガメニュー`
→ `記事ページ`

記事ページ内は次の順を基本とする。

1. パンくず
2. H1
3. 導入文
4. ページ内目次（必要な場合）
5. 本文・数式・図
6. 補足・修正情報
7. 関連コンテンツ
8. フッター

本体への実装・本番反映は、数式監査とデザイン最終確認を経て実施する。

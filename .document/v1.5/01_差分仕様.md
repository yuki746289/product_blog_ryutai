# v1.5 差分仕様

更新日: 2026-09-16

## UI-NAV-004 [MOD / 既存表示改善]
変更前: PC左メニューは親領域175px、iframe/内部メニュー180pxを基準とし、モバイル初期化処理でPCにも `scrolling=auto` が設定される。
変更後: 現行UIを使用している期間は、PC左メニューの親領域・iframe・内部メニューの実効幅を整合させ、右端文字を切らない。PCではiframe縦スクロールを原則表示せず、767px以下のスマホでオフキャンバーメニューを開く場合だけ縦スクロールを許可する。広告見出しは他見出しと同じ中央揃え・幅に統一する。
理由: 本体デザイン切替前の現行ページでも文字切れ等を発生させないため。
影響: `menu.html`, `css/lib.css`, `css/responsive.css`。

## UI-NAV-005 [ADD / 採用方向]
変更前: PCは左固定メニューを主ナビゲーションとする。
変更後: 本体デザイン更新時にPCの左固定メニューを廃止し、上部カテゴリ＋メガメニューへ移行する。

### PC
- 上部カテゴリは `物理 / 流体力学 / 有限要素法 / メッシュ / SIMPLE法 / 伝熱工学 / Fortran / その他` の8カテゴリを基本とする。
- カテゴリ選択時、下方向へ1枚のメガパネルを展開する。
- 深い階層は横方向の多段フライアウトにせず、メガパネル内の章グループ、親項目、インデントで表現する。
- クリックで開閉し、外側クリック・Escapeで閉じる。

### スマートフォン
- ハンバーガーから右ドロワーを開く。
- カテゴリと下位階層は `<details>` 相当のアコーディオンで表示する。
- ドロワー内部を縦スクロール可能とする。
- 閉じたドロワー内へキーボードフォーカスが入らないようにする。

理由: 深い技術階層を維持しながら、左固定領域をなくし本文幅と閲覧性を改善するため。
参考実装: `design_samples/v1.5/gray/mega-menu-preview.html`

## UI-HISTORY-002 [MOD]
変更前: 修正履歴テーブルは `ID / 対象 / 修正内容` を表示する。
変更後: 表示列を `No. / 修正種類 / 対象 / 修正内容` に変更する。No.は画面表示用の連番とし、修正種類は「誤記修正」「数式修正」「補足追加」「表示改善」「操作性改善」等の利用者向け分類を表示する。既存の `R-*` 管理IDは画面列として表示せず、必要な追跡情報はHTMLコメント等で保持する。
理由: 利用者にとってIDよりも修正の性質が把握しやすいため。
影響: `revision_history.html`, `css/math.css`。

## FORMULA-FIDELITY-001 [ADD]
変更前: 数学的整合性や可読性を理由として、元画像と数学的に同値な一般化・補足・書き換えをLaTeX化時に採用できる場合があった。
変更後: 数式画像のLaTeX/MathJax化では、**元画像の式そのものを忠実に再現することを一次要件**とする。

- 数学的同値性だけでは一致とみなさない。
- 項順、符号、係数、添字、括弧、行列成分、等号関係を元画像と一致させる。
- x/y/z個別式を一般化式へ統合しない。
- 原画像にない総和記号、Kronecker delta、補助変数、行列略記等を導入しない。
- 誤記・理論上の修正・補足は原文式とは別表示にする。
- 元画像を照合用として保持する。
- `.document/CHECKLIST_FORMULA_CONVERSION.md` のPass 1 / Pass 2を全式に適用する。
- 2026-09-16以前の変換済み数式は再監査する。

## 重要な確認事項

### R-FEM2D-MOM-001: 積分領域 `V,dV` と `S,dS`

`image003` は

- `V`
- `dV`

を使用するが、`image005` 以降は

- `S`
- `dS`

を使用する。

2D三角形要素であり、後半の積分公式も面積 `A` と領域 `S` を使用しているため、`image003` の `V,dV` は前ページ `fem_7_1_1.html` と同様に表記誤りの可能性がある。

**対応方針:** 自動修正せず、原文版と修正候補を分ける。

### R-FEM2D-MOM-002: 内挿式末尾の `=0`

`image004` は

- `V_x = N_1V_{x,1}+N_2V_{x,2}+N_3V_{x,3} = [N]{V_x} = 0`
- `V_y = N_1V_{y,1}+N_2V_{y,2}+N_3V_{y,3} = 0`

と読める。

一般の速度場の内挿式が恒等的に0になる理由はなく、直後の式でも `{V_x}`, `{V_y}` は未知量として使用される。

**判定:** 原文誤植の可能性が非常に高い。

### R-FEM2D-MOM-003: 線積分公式

原文:

`∫_L L_1^p L_2^q dL = p!q!/(p+q)! · L`

標準的な一次線要素（区間長 `L`、端点形状関数 `L_1,L_2`）では

`∫_L L_1^p L_2^q dL = p!q!/(p+q+1)! · L`

となる。

したがって

`∫_L L_i dL = L/2`

であり、原文の `L` とは一致しない。

この差は `image032` 以降の表面張力項へ直接伝播する。

**対応方針:** LaTeX化前に原文維持か数式修正かを明示的に決定する。勝手に修正しない。

### R-FEM2D-MOM-004: 面積積分公式中の `V`

`image027` の `i=j` の途中計算に

`4/4! V`

とあるが、前後はすべて面積 `A` を使用し、最終結果も `A/6`。

**判定:** `A` の誤植と考えるのが自然。

### R-FEM2D-MOM-005: `image038` の `i=1,2,3`

前後:

- `image037`: `i=1,2`
- `image038`: `i=1,2,3`
- `image039`: `i=1,2`
- `image040`: `i=1,2`

このページは2D運動量式のため、方向添字 `i` は2成分。

**判定:** `i=1,2,3` は誤記の可能性が高い。

## Green-Gauss / 応力項の整合確認

重み付き残差中の応力発散項

`-∫_S N^T ∂σ^*_{xi}/∂X dS - ∫_S N^T ∂σ^*_{yi}/∂Y dS`

にGreen-Gaussを適用すると、

- 領域内部: `+∫_S (∂N/∂X)^T σ^*_{xi} dS + ∫_S (∂N/∂Y)^T σ^*_{yi} dS`
- 境界: `-∫_L N^T(σ^*_{xi}n_x+σ^*_{yi}n_y)dL`

となり、`image008`～`image009` の符号は整合する。

その後の

`σ^*_{xi} = -δ_{xi}P + (1/Re)(∂V_i/∂X + ∂V_x/∂x_i)`

`σ^*_{yi} = -δ_{yi}P + (1/Re)(∂V_i/∂Y + ∂V_y/∂x_i)`

への展開も、`image010`～`image014` と整合する。

## 最終成分式の整合確認

一般式の粘性項を `i=x` と `i=y` に展開すると、

### x方向

- `{V_x}` に `2[S_xx]+[S_yy]`
- `{V_y}` に `[S_yx]`
- 圧力に `-[H_x]{P}`

### y方向

- `{V_x}` に `[S_xy]`
- `{V_y}` に `[S_xx]+2[S_yy]`
- 圧力に `-[H_y]{P}`

となり、`image041`, `image042` と一致する。

## 監査方法

- GitHub Actions run: `35283846226`
- Chromium（Playwright）でローカルHTTPサーバ上の監査ページを開き、MathJaxの起動完了後に各式を実描画した。
- 各式について以下を成果物として生成した。
  - 元数式画像を白背景へ正規化した画像
  - ブラウザ上のMathJax描画スクリーンショット
  - 上記2枚を上下に並べた目視比較画像
  - DOM寸法・横方向オーバーフロー有無を記録した `manifest.json`
- 自動画像一致判定だけでPassにはしない。最終判定は比較画像を式単位で目視して行った。
- 元画像が正本であり、数学的に同値であっても元画像にない簡略化・一般化・訂正はPass対象に含めない。

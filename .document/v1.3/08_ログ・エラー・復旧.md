# v1.3 ログ・エラー・復旧

## BAT-LOCAL-ERR-001

### ログ
- 標準出力へ主要処理の開始・完了を表示する。
- エラーは標準エラーへ表示する。
- 秘密情報は出力しない。

### 異常終了条件
- Gitリポジトリとして認識できない。
- 現在ブランチが `develop` ではない。
- `index.html` が存在しない。
- Apacheルート、`httpd.exe`、`httpd.conf` が存在しない。
- Apache設定テストが失敗する。
- コピー後の `index.html` が存在しない。
- Apache起動または `localUrl` のHTTP疎通が失敗する。

### 警告扱い
- 作業ツリーに未コミット差分がある場合は警告するが、ローカル確認用途のため継続する。
- HTTP疎通成功後の既定ブラウザ起動に失敗した場合はURLを表示して終了コード0とする。

### 復旧
- コピー途中失敗: 原因解消後 `./deploy_local.sh` を再実行する。
- Apache起動失敗: `httpd.exe -t` のエラーを解消して再実行する。
- Git更新失敗: `git pull --ff-only origin develop` を解消後に再実行する。

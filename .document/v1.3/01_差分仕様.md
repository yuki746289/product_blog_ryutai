# v1.3 差分仕様

v1.3 はローカル配備 batch の初版。比較対象となる同種 batch 仕様は存在しないため全項目を ADD とする。

|仕様ID|区分|変更前|変更後|理由|影響範囲|対応先|
|---|---|---|---|---|---|---|
|BAT-LOCAL-SCOPE-001|ADD|ローカル配備手順なし|Windowsローカル確認環境を定義|ユーザ依頼|ローカルのみ|02|
|BAT-LOCAL-EXEC-001|ADD|手順なし|Git Bashでpull後にsh実行|運用統一|開発PC|03|
|BAT-LOCAL-IN-001|ADD|入力定義なし|develop作業ツリーを入力|最新版確認|repo|04|
|BAT-LOCAL-OUT-001|ADD|出力定義なし|`C:\server\Apache24\htdocs\ryutai`|root直下回避|Apache|04|
|BAT-LOCAL-PROC-001|ADD|コピー処理なし|対象をクリア後に公開ファイルをコピー|残骸防止|Apache公開領域|05|
|BAT-LOCAL-PROC-002|ADD|Apache確認なし|設定チェック・必要時起動|表示可能化|Apache|05|
|BAT-LOCAL-PROC-003|ADD|HTTP確認なし|URL疎通後にブラウザを開く|確認簡略化|localhost|05|
|BAT-LOCAL-FILE-001|ADD|除外定義なし|`.git/.github/.document/.rules`等を除外|公開不要ファイル排除|コピー対象|06|
|BAT-LOCAL-SEC-001|ADD|非接触条件なし|FTP・本番・秘密情報に触れない|安全性|本番環境|07|
|BAT-LOCAL-ERR-001|ADD|異常時仕様なし|必須条件失敗時に非0終了|誤配備防止|実行制御|08|
|BAT-LOCAL-ACC-001|ADD|受入条件なし|`http://localhost/ryutai/` HTTP成功|完了判定|ローカル表示|09|
|BAT-LOCAL-HIST-001|ADD|履歴なし|v1.3初版を記録|追跡性|文書|10|

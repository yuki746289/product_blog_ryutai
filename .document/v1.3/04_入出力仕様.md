# v1.3 入出力仕様

## BAT-LOCAL-IN-001 入力

|項目|仕様|
|---|---|
|入力元|ローカルGitリポジトリの作業ツリー|
|想定パス|`C:\Users\yuki_\OneDrive\Documents\github\product_blog_ryutai`|
|ブランチ|`develop`|
|必須ファイル|`index.html`, `css/`, 各公開HTML/画像等|
|前提|ユーザが事前に `git pull --ff-only origin develop` を実施済み|
|文字コード|元ファイルをそのまま保持|
|入力なし時|必須ファイルが無い場合は異常終了|

## BAT-LOCAL-OUT-001 出力

|項目|仕様|
|---|---|
|出力先|`C:\server\Apache24\htdocs\ryutai`|
|Git Bash表記|`/c/server/Apache24/htdocs/ryutai`|
|URL|`http://localhost/ryutai/`|
|上書き|既存 `ryutai` をクリアして再作成|
|除外|開発管理用ディレクトリ・スクリプト等|
|ログ|標準出力/標準エラー|
|0件|コピー後に `index.html` が無ければ異常終了|

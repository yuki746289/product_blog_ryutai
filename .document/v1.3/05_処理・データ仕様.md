# v1.3 処理・データ仕様

## BAT-LOCAL-PROC-001 公開ファイルコピー
1. スクリプト自身の位置から `repoRoot` を決定する。
2. Git管理下か、現在ブランチが `develop` かを確認する。
3. Apache公開先 `targetDir` を削除・再作成する。
4. tarストリームでサイトをコピーする。
5. `.git`, `.github`, `.document`, `.rules`, `responsive_navigation_v1.1`, `deploy_local_v1.3`, `deploy_local.sh` 等の開発管理物は除外する。
6. コピー後 `targetDir/index.html` の存在を確認する。

## BAT-LOCAL-PROC-002 Apache確認・起動
1. `httpd.exe` と `httpd.conf` の存在を確認する。
2. `httpd.exe -t -f httpd.conf` で設定テストを行う。
3. localhostが既に応答する場合は起動処理を省略する。
4. 未応答の場合はApacheをバックグラウンド起動し、短時間リトライする。
5. Apache設定は自動変更しない。

## BAT-LOCAL-PROC-003 HTTP確認・ブラウザ起動
1. `localUrl` へHTTP GETを行い成功を確認する。
2. 成功時、Windowsの既定ブラウザで `localUrl` を開く。
3. ブラウザ起動失敗は警告扱いとし、HTTP成功なら配備自体は成功とする。

## データ仕様
DB/テーブル/永続データの更新は該当なし。静的ファイルコピーのみ。

## 冪等性
同じ入力状態で再実行した場合、`htdocs/ryutai` は同じ公開内容になる。途中失敗時も再実行で復旧可能とする。

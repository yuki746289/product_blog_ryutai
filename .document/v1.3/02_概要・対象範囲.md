# v1.3 概要・対象範囲

## BAT-LOCAL-SCOPE-001

### 概要
Git BashからローカルApacheへサイトを配備し、`http://localhost/ryutai/`で確認できるようにする。

### 対象範囲
- リポジトリ: `C:\Users\yuki_\OneDrive\Documents\github\product_blog_ryutai`
- ブランチ: `develop`
- Apache: `C:\server\Apache24`
- 配置先: `C:\server\Apache24\htdocs\ryutai`
- Git Bash用シェルスクリプト
- Apache設定テスト、必要時起動、HTTP疎通、ブラウザ起動

### 非対象範囲
- 本番FTPへのアップロード
- `release_1.0.0` の変更
- サイト本文・数式・CSS等の追加修正
- Apache設定ファイルの自動書換え
- Windowsサービスのインストール/削除

### 用語
- repoRoot: リポジトリルート
- apacheRoot: `C:\server\Apache24`
- targetDir: `htdocs\ryutai`
- localUrl: `http://localhost/ryutai/`

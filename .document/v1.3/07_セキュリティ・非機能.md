# v1.3 セキュリティ・非機能

## BAT-LOCAL-SEC-001

### セキュリティ
- 本番FTPへ接続しない。
- GitHub Secrets、FTPユーザ名・パスワード等を参照・出力しない。
- Apache設定ファイルを自動変更しない。
- コピー対象はローカルリポジトリからローカルApacheのみ。
- `htdocs/ryutai` 以外の公開領域を削除しない。

### 非機能
- Windows + Git Bashで実行可能であること。
- パスは引用符で囲み、将来空白を含むパスでも破綻しにくくする。
- 元ファイルの文字コード・改行はコピー時に変換しない。
- 再実行可能であること。
- エラー時は非0終了し、成功扱いにしない。
- HTTP確認は `curl` を使用する。
- 公開URLは `http://localhost/ryutai/` を維持する。

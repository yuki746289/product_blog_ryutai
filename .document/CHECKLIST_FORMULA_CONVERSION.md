# 数式画像 → LaTeX/MathJax 変換チェックリスト

## 目的

数式画像をテキスト数式へ置換する際に、画像の転記精度だけでなく、前後の式変形・有限要素法上の整合性・記号定義・表示品質まで確認する。

## 基本方針

- 単純OCR結果をそのまま採用しない。
- 必ず「元画像との一致確認」と「前後の数式との整合性確認」を分けて行う。
- 原文に誤植の可能性がある場合は、勝手に修正しない。
  - `原文どおり`
  - `理論上の推定`
  - `要確認`
  を分けて記録する。
- 図、グラフ、メッシュ図、座標図などは数式画像と混同せず、原則画像を維持する。

## A. 数式画像の判定

- [ ] 対象が数式画像であり、図・グラフ・模式図ではない。
- [ ] 使用ページ、画像パス、前後の説明文を記録した。
- [ ] 同じ画像が複数ページで再利用されていないか確認した。
- [ ] 低解像度・文字潰れ・添字不鮮明など、読み取りリスクを記録した。

## B. 画像 → LaTeX 転記確認

- [ ] 変数名、大文字/小文字が元画像と一致している。
- [ ] 上付き、下付き、時刻添字、節点番号が一致している。
- [ ] ギリシャ文字、偏微分記号、ナブラ、積分記号が一致している。
- [ ] ベクトル、行列、スカラーの区別が一致している。
- [ ] 括弧、波括弧、角括弧、転置記号が一致している。
- [ ] 積分領域（S, V, Γ 等）と微小量（dS, dV 等）が一致している。
- [ ] 分数、係数、Ma, Re 等の無次元数が一致している。
- [ ] ±符号を元画像と照合した。
- [ ] 行列の行・列数、成分位置を元画像と照合した。

## C. 前後の式変形の数学的整合性

各式について、直前式からの変形理由を明示する。

- [ ] 代入による変形か確認した。
- [ ] 項分解・展開による変形か確認した。
- [ ] 共通因子のくくり出しが正しい。
- [ ] 既知量・節点値を積分の外へ出す操作が妥当。
- [ ] 移項時に符号が正しく変化している。
- [ ] 時刻項の `τ` と `τ+Δτ` の扱いが前後で一貫している。
- [ ] 微分・積分の次数が前後で一致している。
- [ ] 次元数（2D/3D）を跨いだ成分抜けがない。

## D. 有限要素法固有の整合性

- [ ] 重み関数と形状関数の定義がページ内で一貫している。
- [ ] `N_i` と節点値の内挿式が正しい形で使用されている。
- [ ] 重み付き残差式の積分領域が適切。
- [ ] 部分積分／グリーン・ガウス適用前後で境界項が整合している。
- [ ] 境界積分項の符号と法線方向の扱いが整合している。
- [ ] 形状関数の微分値と要素座標系の定義が整合している。
- [ ] 三角形一次要素・四面体一次要素など、対象要素に対応した積分公式になっている。
- [ ] 面積 A、体積 V、Jacobian 等の係数が前後で整合している。
- [ ] 質量行列、勾配行列、係数行列のサイズが節点数と一致している。
- [ ] 最終連立方程式の未知ベクトルと係数行列の次元が一致している。

## E. 流体力学固有の整合性

- [ ] 連続の式と運動量式で使用する変数定義が一致している。
- [ ] `V_x, V_y, V_z`、`P`、応力成分の添字が一貫している。
- [ ] `σ_xx, σ_xy, σ_xz, ...` の成分対応に誤りがない。
- [ ] 圧力項・粘性項・慣性項・時間項の符号が前式と一致している。
- [ ] 2次元式から3次元式への拡張で z 成分・z 微分の抜けがない。
- [ ] 無次元化係数（Ma, Re 等）が途中で欠落・重複していない。

## F. 積分公式・行列化確認

- [ ] 使用した積分公式を独立に再計算できる。
- [ ] 三角形一次要素では、必要に応じて次を確認する。
  - `∫_S L_i dS = A/3`
  - `∫_S L_i^2 dS = A/6`
  - `∫_S L_i L_j dS = A/12 (i ≠ j)`
- [ ] 四面体一次要素では対応する体積積分公式を確認する。
- [ ] 数値係数（1/2, 1/3, 1/6, 1/12 等）が前式から正しく導かれている。
- [ ] 行列へまとめる際に成分順序が変わっていない。
- [ ] 行列を略記号 `[C]`, `[C_x]`, `[C_y]` 等へ置換した場合、定義元と一致している。

## G. 原文誤植の扱い

- [ ] 原画像とLaTeXが一致しているかをまず判定した。
- [ ] 前後の式から見て原文に誤植の疑いがある場合、勝手に修正していない。
- [ ] 誤植候補を `要確認` として記録した。
- [ ] 修正する場合は、元画像の内容と修正理由を履歴に残した。

## H. MathJax / HTML 表示確認

- [ ] PCで数式が崩れない。
- [ ] スマホでページ全体の横スクロールを発生させない。
- [ ] 長い数式だけ必要に応じて数式領域内スクロールにする。
- [ ] 行列・cases・align等がMathJaxで正常表示される。
- [ ] 既存本文のCP932文字コードを不要に変更していない。
- [ ] 画像削除前に、置換後表示と元画像を並べて確認した。

## I. ページ単位の完了条件

以下をすべて満たした場合のみ、そのページを変換完了とする。

- [ ] 数式画像をすべて分類済み。
- [ ] 対象数式をすべてLaTeX化済み。
- [ ] 元画像との転記一致確認済み。
- [ ] 全ての連続する式について前後整合性確認済み。
- [ ] FEM/流体力学上の整合性確認済み。
- [ ] 誤植候補が未処理で残っていない、または明示的に保留記録済み。
- [ ] PC表示確認済み。
- [ ] スマホ表示確認済み。
- [ ] 旧数式画像を削除する場合、未参照を確認済み。

### 判定値

- `OK`: 問題なし
- `要確認`: 画像が不鮮明、複数解釈、原文誤植疑い等
- `原文維持`: 理論上疑義はあるが原文どおり変換
- `修正承認済`: 原文誤植を確認後に修正
- `画像維持`: 数式ではなく図等のため変換対象外

## レビュー順序

1. 元画像を読む。
2. LaTeXへ転記する。
3. 元画像とLaTeXを一文字・一記号単位で照合する。
4. 直前式から当該式への変形を再計算する。
5. 当該式から次式への変形も確認する。
6. FEM・流体力学としての意味を確認する。
7. MathJax表示を確認する。
8. 問題がなければページ単位で完了判定する。

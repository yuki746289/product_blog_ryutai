# 数式画像 → LaTeX/MathJax 変換チェックリスト

更新日: 2026-09-16

## 目的

数式画像をLaTeX/MathJaxへ置換する際、**元画像に記載された式を忠実に再現することを最優先**とする。
数学的に同値か、理論上より自然か、誤記と思われるかは別問題として扱い、元画像の式そのものを無断で書き換えない。

## 最優先ルール: Source Fidelity

### 1. 元画像の式をそのまま再現する

- LaTeX/MathJax化する式は、元画像と**文字・記号・添字・上付き・係数・符号・項順・括弧・等号・行列成分・式の並び・行分割の論理構造まで一致**させる。
- 「数学的に同値」は一致とみなさない。
- 次のような書き換えは、数学的に正しくても原則禁止する。
  - 複数項を `\sum` でまとめる。
  - `x,y,z` の各成分式を一般化した `i` 成分式へ置き換える。
  - 原画像の展開式を因数分解・行列化する。
  - 原画像の行列式を別の等価な行列表現へ変更する。
  - 項の順序を入れ替える。
  - 左辺と右辺を入れ替える、または移項する。
  - 記号名・大文字小文字・座標記号を変更する。
  - 原画像にない `\delta`、ベクトル記号、略記号、補助変数等を導入する。
  - 原画像にある `=0`、係数、括弧、添字等を「不要」と判断して削除する。
- MathJaxのフォント・字間・アンチエイリアス等、画像とWeb描画方式の違いによるピクセル単位の差は許容する。ただし**数式として見える構造は元画像と同じ**にする。

### 2. 誤記・理論上の修正・補足は式本体と分離する

- 元画像に誤記と思われる表現があっても、まず「原文式」を元画像どおり表示する。
- 修正候補は、原文式を書き換えず、直後に次のいずれかで明示する。
  - `補足`
  - `誤記の可能性`
  - `修正版（参考）`
- 修正版を数式表示する場合も、**原文式を残したうえで別の式として掲載**する。
- 利用者が明示的に原文式の置換を承認した場合のみ、原文式自体を変更できる。その場合もレビュー履歴に元画像・変更前・変更後・承認理由を残す。

### 3. 1画像 = 1照合単位

- 各数式画像に一意の式IDを付ける。
- `data-source-image` 等で元画像パスを追跡可能にする。
- 複数の画像を1個の一般化式へ統合しない。
- 同一画像が同じページ内で再利用されている場合は、再利用であることを記録し、表示式も同じ内容にする。

### 4. 既存の変換済み数式も再監査する

2026-09-16以前にLaTeX/MathJax化した式は、数学的整合性を優先して一般化・補足・書き換えを行った可能性があるため、**このチェックリストによる再照合が完了するまで「変換完了」と扱わない**。

## A. 数式画像の判定

- [ ] 対象が数式画像であり、図・グラフ・模式図ではない。
- [ ] 使用ページ、画像パス、前後の説明文を記録した。
- [ ] 同じ画像が複数箇所・複数ページで再利用されていないか確認した。
- [ ] 低解像度・文字潰れ・添字不鮮明など、読み取りリスクを記録した。
- [ ] 判読不能部分がある場合、推測で補完せず `要確認` または `画像維持` とした。

## B. 元画像 → LaTeX 転記確認（必須）

各画像について、元画像とMathJax表示を横に並べて照合する。

- [ ] 変数名、大文字/小文字が一致している。
- [ ] ギリシャ文字が一致している。
- [ ] 上付き・下付き・時刻添字・節点番号が一致している。
- [ ] 偏微分・全微分・ナブラ・積分記号が一致している。
- [ ] ベクトル・行列・スカラーの表記が一致している。
- [ ] 括弧 `()`, `[]`, `{}` とその対応範囲が一致している。
- [ ] 転置、逆行列、絶対値、ノルム等の記号が一致している。
- [ ] 積分領域 `S,V,L,Γ` 等が一致している。
- [ ] 微小量 `dS,dV,dL` 等が一致している。
- [ ] 分数の分子・分母が一致している。
- [ ] 数値係数が一致している。
- [ ] `Ma`, `Re`, `We` 等の無次元数と指数が一致している。
- [ ] `+/-` 符号を全項で照合した。
- [ ] 項の並び順が一致している。
- [ ] 左辺・右辺の配置が一致している。
- [ ] 等号・不等号の数と位置が一致している。
- [ ] 原画像の `=0` 等を省略していない。
- [ ] 総和記号の有無と添字範囲が一致している。
- [ ] 行列の行数・列数が一致している。
- [ ] 行列の全成分を位置ごとに照合した。
- [ ] ベクトルの成分数と順序が一致している。
- [ ] `x/y/z` 成分式を一般式へ統合していない。
- [ ] 原画像にない略記・一般化・補助記号を追加していない。
- [ ] 原画像の複数行構造・cases・alignの論理構造を維持している。

## C. 二段階照合

### Pass 1: 転記照合

- [ ] 元画像を見ながらLaTeXソースを1文字・1記号単位で確認した。
- [ ] 特に添字、符号、係数、分母、行列成分を確認した。

### Pass 2: 表示照合

- [ ] ブラウザでMathJax描画後、元画像と並べて目視比較した。
- [ ] 式の構造、項順、行列構造、改行位置の意味が一致している。
- [ ] Pass 1とは別に、もう一度元画像から読み直して確認した。

**Pass 1とPass 2の両方が完了しない式は `画像一致=OK` にしない。**

## D. 数学・物理的整合性確認（元画像一致とは別判定）

元画像への忠実な転記が完了した後で行う。

- [ ] 前後の式変形を確認した。
- [ ] 代入・展開・移項・部分積分等の操作を確認した。
- [ ] 符号・係数・次元を確認した。
- [ ] FEM/流体力学として疑義がないか確認した。
- [ ] 疑義があっても原文式を勝手に変更していない。
- [ ] 疑義がある場合は式の直後またはレビュー文書へ補足した。

## E. 有限要素法固有の確認

- [ ] 重み関数と形状関数の定義がページ内で一貫している。
- [ ] `N_i` と節点値の内挿式を確認した。
- [ ] 重み付き残差式の積分領域を確認した。
- [ ] 部分積分／Green-Gauss適用前後の境界項を確認した。
- [ ] 境界積分項の符号と法線方向を確認した。
- [ ] 形状関数微分値と要素座標系を確認した。
- [ ] 三角形・四面体等、対象要素の積分公式を確認した。
- [ ] 面積 `A`、体積 `V`、Jacobian等の係数を確認した。
- [ ] 質量行列、勾配行列、係数行列のサイズを確認した。
- [ ] 最終連立方程式の未知ベクトルと係数行列の次元を確認した。
- [ ] 境界面局所ベクトルと要素ベクトルの対応に省略がある場合、原式は維持し補足で説明した。

## F. 流体力学固有の確認

- [ ] 連続の式と運動量式の変数定義を確認した。
- [ ] `V_x,V_y,V_z,P` と応力成分の添字を確認した。
- [ ] `σ_xx,σ_xy,σ_xz,...` の成分対応を確認した。
- [ ] 圧力・粘性・慣性・時間・重力・表面張力各項の符号を確認した。
- [ ] 2D/3Dの成分数を確認した。
- [ ] `Ma,Re,We` 等の係数欠落・重複を確認した。

## G. 誤記・補足の表示ルール

- [ ] 原画像どおりの式を先に掲載した。
- [ ] 誤記候補は原式とは別の補足として記載した。
- [ ] 修正版を掲載する場合、「原文」「修正版」が識別できる。
- [ ] 修正版だけを残して原文式を消していない。
- [ ] 補足によって元画像の式IDとの対応が失われていない。
- [ ] 修正・補足の理由をレビュー履歴へ記録した。

## H. MathJax / HTML 表示確認

- [ ] PCで数式が崩れない。
- [ ] スマホでページ全体の横スクロールを発生させない。
- [ ] 長い式は意味を変えずMathJaxの自動改行で表示できる。
- [ ] 長い式を短くする目的で数式自体を一般化・省略していない。
- [ ] 行列・cases・align等が正常表示される。
- [ ] 既存本文の文字コードを不要に変更していない。
- [ ] 元画像ファイルを照合用として保持している。

## I. ページ単位の完了条件

以下を**すべて**満たした場合のみ、そのページを変換完了とする。

- [ ] ページ内の数式画像をすべて列挙した。
- [ ] 各画像に対応する式IDと元画像パスがある。
- [ ] 全数式についてPass 1転記照合済み。
- [ ] 全数式についてPass 2表示照合済み。
- [ ] 全数式で `画像一致=OK` または明示的な `画像維持/要確認` 判定が付いている。
- [ ] 数学・FEM・流体力学上の疑義を別欄で確認済み。
- [ ] 誤記・補足候補を原式と分離して記録済み。
- [ ] PC表示確認済み。
- [ ] スマホ表示確認済み。
- [ ] 元画像を削除していない。

**1式でも未照合ならページ全体を「完了」にしない。**

## J. サイト全体の完了条件

- [ ] 数式画像を使用する全HTMLページを一覧化した。
- [ ] 全ページについて式数・画像数を記録した。
- [ ] 全画像について元画像→MathJaxの照合結果が記録されている。
- [ ] `未確認` が0件になっている。
- [ ] `要確認` は理由と扱いが明記されている。
- [ ] 既存変換済みページも新ルールで再監査済み。

### 判定値

- `OK`: 元画像一致・表示確認済み。
- `要確認`: 画像不鮮明、複数解釈、判読不能等。
- `原文維持`: 理論上の疑義や誤記候補はあるが、元画像どおり表示。
- `補足あり`: 原文式を維持し、別途補足を追加。
- `修正版併記`: 原文式を維持したまま参考修正版を別表示。
- `修正承認済`: 利用者の明示承認により原文式自体を変更。
- `画像維持`: 数式ではない、または忠実な転記が困難なため画像のまま維持。

## レビュー順序

1. `release_1.0.0` または変換前履歴から元HTMLと元画像を特定する。
2. 元画像を読む。
3. 元画像どおりLaTeXへ転記する。
4. Pass 1として1文字・1記号単位で照合する。
5. ブラウザでMathJax表示する。
6. Pass 2として元画像とMathJax表示を横並びで再照合する。
7. 元画像一致を確定した後で、数学・FEM・流体力学上の整合性を確認する。
8. 誤記・省略・理論上の疑義は原式と分離して補足する。
9. PC/スマホ表示を確認する。
10. ページ内全式が完了した場合だけページを完了にする。

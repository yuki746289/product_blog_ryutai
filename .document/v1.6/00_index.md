# v1.5 仕様書インデックス

対象: 左メニュー表示修正・修正履歴改善・デザイン比較サンプル
基準: v1.4 サイト表示・ナビゲーション改善仕様を継承
未決事項: なし（デザイン本採用案はサンプル確認後に別途決定）

## 変更概要
- PC左メニューの右端文字切れを解消する。
- PCではメニューiframeの不要な縦スクロールを抑止し、スマホのハンバーガーメニューのみ縦スクロールを許可する。
- ハンバーガーメニュー内の「広告」見出しを他のセクション見出しと同じ中央揃え・幅へ統一する。
- 修正履歴テーブルを `No. / 修正種類 / 対象 / 修正内容` 構成へ変更する。
- 画面表示用の管理ID列は廃止し、追跡用IDはHTMLコメント等の内部情報として維持する。
- 本体へ適用しない比較用デザインサンプルを3案作成する。
  - A: Technical Clean
  - B: Academic Minimal
  - C: Modern Dashboard
- サンプルはPC/スマホ双方で表示でき、ユーザ確認後に採用案を決定する。

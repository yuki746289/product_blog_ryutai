# site_navigation v1.6 要件定義書

## 1. 目的・背景
[MOD] v1.5で選定したD Monochrome Notesと多層メニュー実動サンプルを、本体サイトへ安全に適用する。約190ページの既存HTMLを個別変更せず、共通 `menu.html` と共通CSS/JavaScriptを利用して移行する。

## 2. 対象範囲
[MOD] `menu.html`
[MOD] `css/lib.css`（新共通CSS読込との整合のみ）
[KEEP] `css/responsive.css`（既存フォールバック。新CSSで必要な上書きを行う）
[ADD] `css/site_v1_6.css`
[ADD] `js/site_navigation_v1_6.js`
[KEEP] 各記事HTML・数式画像・本文

## 3. 対象外
- 記事URL変更
- 記事本文の意味内容変更
- 数式画像・TeX式の内容変更
- `*_mathjax_audit.html` の本番公開
- 外部UIフレームワーク導入
- 本番FTP反映

## 4. 機能要件

### [S001][MOD] 共通ナビ初期化
- `menu.html` iframe読込時、親ページが存在する場合だけ新ナビを初期化する。
- 親ページへ `css/site_v1_6.css` を1回だけ追加する。
- 新ナビ初期化成功後にだけ親bodyへ `rv-nav-ready` を付与する。

### [S002][ADD] PCメガメニュー
- PC/タブレットで8カテゴリを上部表示する。
- 8カテゴリは物理、流体力学、有限要素法、メッシュ、SIMPLE法、伝熱工学、Fortran、その他。
- 既存 `menu.html` のリンクDOMを情報源とする。
- `anchor.href` の解決済みURLを使用し、nestedページでもリンクを壊さない。
- 深い階層は1枚のメガパネル内でインデント表示する。
- クリック、外側クリック、Escapeで開閉する。

### [S003][ADD] スマホドロワー
- 767px以下でハンバーガーを表示する。
- 右ドロワー内に8カテゴリをアコーディオン表示する。
- 下位階層をカテゴリ内で展開できる。
- Escape、閉じるボタン、オーバーレイで閉じる。
- 閉状態は `aria-hidden` / `inert` / `aria-expanded` を同期する。

### [S004][ADD] 補助リンク
- ホーム、はじめに、プロフィール、Q&A、サイトマップ、メール、リンク、修正履歴等への既存導線を新UIでも維持する。

### [S005][ADD] D Monochrome本文レイアウト
- 左固定メニューを本文領域から除外する。
- 白地、グレー罫線、低装飾を基本とする。
- 本文最大幅を制限し中央配置する。
- 既存画像・表・iframeをレスポンシブ表示する。
- 数式内容は変更しない。

### [S006][KEEP] フォールバック
- 新JSが実行できない場合は従来HTML・従来menu iframeを維持する。
- 初期化エラーで本文を削除しない。

## 5. 非機能要件
- PC1365px、タブレット768px、スマホ390pxで確認する。
- ページ横スクロール、文字欠落、重なりを発生させない。
- キーボード操作とARIA状態を維持する。
- 新規コードは外部フレームワーク不要とする。
- 既存CP932 HTMLを不要に文字コード変換しない。

- [ ] 8カテゴリが欠落しない。

- [ ] PC開閉・カテゴリ切替・外側クリック・Escapeが動作する。
- [ ] スマホドロワー・アコーディオン・スクロール・Escapeが動作する。
- [ ] 閉ドロワーへTabフォーカスが入らない。
- [ ] nestedページから既存リンクが正しいURLへ遷移する。
- [ ] 数式画像src、TeX式、本文内容にデザイン変更由来の差分がない。
- [ ] JS失敗時も本文が読める。

# site_ui v1.5 要件定義

## 1. 目的・背景
v1.4でレスポンシブ・MathJax表示を改善した後の実機確認で、PC左メニューの右端文字切れ、ページによるメニューiframe縦スクロール表示、モバイルメニュー内「広告」見出しの位置ずれが確認された。加えて、修正履歴の管理ID表示を利用者向け情報へ整理し、今後の全面デザイン刷新に向けた比較サンプルが必要となった。

## 2. 対象範囲
- [MOD] `menu.html`, `css/lib.css`, `css/responsive.css`
- [MOD] `revision_history.html` と修正履歴表示CSS
- [ADD] `design_samples/v1.5/` の比較用デザイン3案

## 3. 対象外
- [KEEP] 数式内容・MathJax 4設定
- [KEEP] 既存URL
- [KEEP] 本番FTP
- [KEEP] デザインサンプルの本体全ページ展開

## 4. 機能要件
- REQ-UI-001 [KEEP] 数式は横スクロールなし・自動改行を維持する。
- REQ-UI-002 [KEEP] トップ更新告知を維持する。
- REQ-UI-003 [KEEP] 修正履歴リンク位置を維持する。
- REQ-UI-004 [MOD] スマホのメニューiframeを縦スクロール可能にする一方、PCではiframe自身の不要な縦スクロールを抑止する。
- REQ-UI-005 [MOD] PC左メニューのリンク文字を右端まで表示する。
- REQ-UI-006 [MOD] モバイルメニュー内の「広告」を他セクション見出しと同じ中央揃え・幅にする。
- REQ-UI-007 [MOD] 修正履歴を `No. / 修正種類 / 対象 / 修正内容` の4列へ変更する。
- REQ-UI-008 [ADD] Technical Clean / Academic Minimal / Modern Dashboard の3サンプルを作成する。
- REQ-UI-009 [ADD] サンプル一覧から3案を比較できるようにする。

## 5. 非機能要件
- PC1365px、スマホ390pxで表示確認する。
- 左メニュー・サンプルページで意図しない横スクロールを発生させない。
- サンプルは外部UIフレームワークに依存せず、静的HTML/CSSで成立させる。
- CP932の既存HTMLは文字コードを維持する。

## 6. 制約条件
- v1.4のMathJax・レスポンシブ・既存URLを維持する。
- サンプルは `design_samples/v1.5/` の独立領域に限定し、本体の正式デザインとして扱わない。
- 本番FTPへデプロイしない。

## 7. 受入条件
`.document/v1.5/09_図・受け入れ条件.md` の ACC-UI-009〜013 および ACC-DESIGN-001〜004を満たす。

## 8. 未決事項
本体に採用するデザイン案はサンプル確認後に決定する。サンプル作成の実装上の未決事項はない。
